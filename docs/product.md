# Product definition — Noor (working title)
Confirmed: ages 6–8; simplified Arabic MSA text and voice; lantern mascot Noor; common fiqh fundamentals then attributed differences; basic parent progress/results/sources; all four worlds; tablet-first and responsive mobile.
## Loop
Learn 1–2 short facts with audio and illustration → 3–5 challenges → explanatory feedback → stars/XP → review. Sessions 3–5 min. No countdown. Retry without penalty. Review wrong answers later; randomize answer positions. Flashcards are self-assessed, not graded knowledge evidence.
## Worlds / initial content targets
| World | Three proposed lessons |
|---|---|
| الإيمان | من ربنا؟ / معنى الشهادتين / أركان الإيمان |
| العبادة | أركان الإسلام / الوضوء / الصلوات الخمس |
| السيرة | نسب النبي ﷺ ومولده / نزول الوحي / الهجرة |
| القدوات | الخلفاء الراشدون / العشرة المبشرون بالجنة / التعرف على الأئمة الأربعة |
These are topic proposals, not verified religious content. Later: detailed prayer fiqh, purity, fasting, zakat, hajj, companions, tabi‘un and stories.
## MVP priorities
P0: four worlds, 12 target lessons (minimum one approved lesson per world for release), choice/true-false/flashcards, feedback, local progress, audio controls, sources in parent mode. P1: matching/ordering, review queue, daily challenge, enhanced rewards. Defer collectible world builder, streaks, backend, additional profiles, adaptive curriculum and elaborate animation.
## Success
Child can choose a world and finish a lesson with minimal assistance; voluntarily wants another lesson. Parent can see learning progress and sources. No unsupported religious claims shipped. Observe rather than collect telemetry.
