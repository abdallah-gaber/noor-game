# 004-06 preview Parent Mode

Use **وضع الوالدين** from preview home. For the authored pilot, the adult-review gate protects home and direct routes. The report is Arabic, read-only and local. It shows saved completion by world and lesson, knowledge-level first, recent and eventual correctness, strengths, review needs, scheduled recommendations and recent practice. Seeded preview unlocks are excluded from saved completion totals. A recommendation can open the existing adaptive review.

The private pilot adapter preserves authored source titles, locators and any supplied addresses. Parent Mode presents them as selectable offline text under the matching lesson and labels them as pending verification. Synthetic lessons show that they have no religious references. The view reads preview progress and history, and requires no account or network.
