[PR #5](https://github.com/abdallah-gaber/noor-game/pull/5) merged the signed starter into `main` at `7e57c6b1f8afc207dcca391cdb902bc8add1be17`. The tracked Android release is v0.1.1 build 5. The physical low-end Android check remains tracked in SPEC-005. The prototype branch started at the verified merge.

## Launch and play

Run `flutter run --debug --route=/preview/adventure/w06` from the Flutter checkout. The same route is available from **معاينة المطوّر** → **معاينة مغامرة الوضوء** in a debug build. For the Android emulator capture, the existing `ORG_GRADLE_PROJECT_noorAdultReview=true` build property installed a separate debug package with the standard `lib/main.dart` entry point.

Drag the blue droplet from the tap onto the palms. You can also tap the droplet, then tap the palms. The scene shows a splash, Noor reacts, and replay becomes available. A missed drop leaves the activity ready to try again. The existing audio preference controls its bundled non-musical sounds.

The route requires the validated W06 lesson and W06.K1 in the approved starter catalog. It illustrates the palm-washing action, with no sequence, required washing count, or assessment. The interaction's state lasts for the visit. Independent evaluation and progress integration belong to 006-03.
