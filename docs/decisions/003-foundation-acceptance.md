# ADR 003 — Foundation acceptance and release hardware gate

Accepted by the project owner on 2026-11-26. The owner reported ten passing smoke checks on a physical tablet and accepted SPEC-001. The owner’s report complements the automated, build and emulator evidence. [Foundation QA](../qa/spec-001/results.md)

The child’s low-end Android tablet check now belongs to SPEC-005 as P0 task 005-06. Running the final release candidate there will verify the actual navigation, progress and audio behavior under the intended hardware constraints. Keep observations anonymized and distinguish emulated behavior from physical hardware performance. [Release specification](../../specs/005-release-and-playtest/spec.md)
